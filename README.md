# CSV Relationship Finder

Discover likely relationships between multiple CSV datasets and visualize them as a lightweight ER-style graph.

## What it does

- Infers candidate key columns.
- Compares column names and value overlap across files.
- Suggests likely PK/FK relationships with a transparent confidence score.
- Draws a relationship graph in the browser.

## Usage

Add two or more CSV datasets, then select **Find relationships**.

## Privacy

Files never leave the browser.
